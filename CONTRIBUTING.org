#+TITLE: Contributing to Konigslibrary

* Prerequisites

- [[https://bun.sh/][Bun]]

* Setup

#+begin_src sh
git clone https://github.com/NasreddinHodja/konigslibrary.git
cd konigslibrary
bun install
bun dev
#+end_src

* Available Scripts

| Command            | Description               |
|--------------------+---------------------------|
| =bun dev=          | Start dev server          |
| =bun run build=    | Production build          |
| =bun run check=    | Svelte type checking      |
| =bun run lint=     | Prettier + ESLint check   |
| =bun run format=   | Auto-format with Prettier |
| =bun run test=     | Run tests                 |

* Code Style

This project uses Prettier and ESLint for consistent formatting. Configuration lives in [[file:.prettierrc][.prettierrc]] and [[file:.editorconfig][.editorconfig]].

Before submitting code, run:

#+begin_src sh
bun run format
bun run lint
#+end_src

* Pull Request Workflow

1. Fork the repository
2. Create a feature branch (=git checkout -b my-feature=)
3. Commit your changes
4. Push to your fork and open a PR against =main=

CI runs lint, type checking, and tests on every PR.

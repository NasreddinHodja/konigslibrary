* Prerequisites

- [[https://bun.sh/][Bun]]
- [[https://rustup.rs/][Rust]], for the archive parser compiled to wasm:

#+begin_src sh
rustup target add wasm32-unknown-unknown
cargo install -f wasm-bindgen-cli --version 0.2.99  # must match crates/klwasm/Cargo.toml
#+end_src

* Setup

#+begin_src sh
git clone https://github.com/NasreddinHodja/konigslibrary.git
cd konigslibrary
bun install
bun dev
#+end_src

* Scripts

| Command                 | Description                                              |
|-------------------------+----------------------------------------------------------|
| =bun dev=               | Dev server                                               |
| =bun run build=         | Production build (adapter-auto)                          |
| =bun run build:local=   | Static build for the local server                        |
| =bun run build:wasm=    | Compile the parser to wasm                               |
| =bun run build:server=  | Build the =konigslibrary-server= binary                  |
| =bun run serve=         | Build and start the local server                         |
| =bun run dev:sim=       | Dev server against a generated library in =dev-library/= |
| =bun run check=         | Svelte type checking                                     |
| =bun run lint=          | Prettier and ESLint check                                |
| =bun run format=        | Auto-format with Prettier                                |
| =bun run test=          | Vitest                                                   |
| =bun run test:rust=     | Parser and server tests (cargo)                          |
| =bun run tauri:local=   | Tauri dev mode                                           |
| =bun tauri build=       | Tauri release build                                      |
| =bun run build:desktop= | Linux AppImage, built in Docker, into =dist/=            |

* Android

Building the Android app also needs the Android SDK and NDK, and a JDK 17 for the Gradle daemon. =src-tauri/gen/android/gradle/gradle-daemon-jvm.properties= requests JDK 17, so Gradle finds or downloads one itself; =JAVA_HOME= doesn't need to change.

=bun run build:android= is unsigned unless a keystore is configured: copy =src-tauri/gen/android/app/key.properties.example= to =key.properties= (gitignored) and fill it in. CI passes the same values as =KEYSTORE_PATH=, =STORE_PASSWORD=, =KEY_ALIAS= and =KEY_PASSWORD= (see [[file:.github/workflows/release-android.yml][release-android.yml]]). Signing happens inside the Gradle build.

* Before a pull request

#+begin_src sh
bun run format
bun run lint
bun run check
bun run test:run
bun run test:rust
#+end_src

CI runs lint, type checking and tests on every PR against =main=.

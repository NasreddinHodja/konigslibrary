* Prerequisites

- [[https://bun.sh/][Bun]]
- [[https://rustup.rs/][Rust]], for the archive parser compiled to wasm:

#+begin_src sh
rustup target add wasm32-unknown-unknown
cargo install -f wasm-bindgen-cli --version 0.2.99  # must match crates/klwasm/Cargo.toml
#+end_src

* Setup

#+begin_src sh
git clone https://github.com/NasreddinHodja/konigslibrary.git
cd konigslibrary
bun install
bun dev
#+end_src

* Android

Building the Android app also needs the Android SDK and NDK, and a JDK 17 for the Gradle daemon. =src-tauri/gen/android/gradle/gradle-daemon-jvm.properties= requests JDK 17, so Gradle finds or downloads one itself; =JAVA_HOME= doesn't need to change.

=bun run build:android= is unsigned unless a keystore is configured: copy =src-tauri/gen/android/app/key.properties.example= to =key.properties= (gitignored) and fill it in. CI passes the same values as =KEYSTORE_PATH=, =STORE_PASSWORD=, =KEY_ALIAS= and =KEY_PASSWORD= (see [[file:.github/workflows/release-android.yml][release-android.yml]]). Signing happens inside the Gradle build.

* Before a pull request

#+begin_src sh
bun run format
bun run lint
bun run check
bun run test:run
bun run test:rust
bun run test:e2e
#+end_src

CI runs lint, type checking and tests on every PR against =main=, the app's own Rust (=src-tauri/=) included, with coverage: a summary on the run's page and the HTML report as its =coverage= artifact. It also benchmarks the PR against =main= and fails on a regression past 15%, and holds the public site's build to a bundle size and Lighthouse budget (see [[file:docs/architecture/performance.org][performance.org]]).

Commit messages follow [[https://www.conventionalcommits.org][Conventional Commits]]. A release's notes are its =feat=, =fix= and =perf= commits since the previous tag, generated by git-cliff (see [[file:cliff.toml][cliff.toml]]); other types and unprefixed commits are left out. A squash merge counts once per commit listed in its body, and once more for its subject (the PR title) if that's prefixed too.

* Tests

Plain modules are tested in Node (=*.test.ts=). Components, and modules using runes or the DOM, are tested in jsdom with Testing Library (=*.svelte.test.ts=). Helpers for those are in =src/lib/testing/=: a reader to mount viewers under, a fake server at =fetch=, the Tauri app through its official IPC mocks, and stand-ins for what jsdom lacks (see =setup-dom.ts=).

=e2e/= drives the self-hosted app in Chromium with Playwright, against the library =dev:sim= generates: browsing, searching, reading, and progress across a reload. Each page it visits is also checked with axe for WCAG 2.1 A and AA violations; page zoom is exempt, since the reader pinches its pages itself. Its tests use the fixed =Order - …= manga, which don't change with =--count=. The first run needs =bunx playwright install chromium=.

=bun run coverage:rust= needs =cargo-llvm-cov= and the =llvm-tools-preview= component.

The budgets run on the public site's build: =STATIC_BUILD=1 bun run build=, then =bun scripts/bundle-budget.js= and =bunx lhci autorun=. Lighthouse needs Chrome or Chromium, through =CHROME_PATH= if it isn't found.

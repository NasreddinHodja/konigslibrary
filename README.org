#+TITLE: konigslibrary
#+DESCRIPTION: Client-side manga reader - Svelte 5, Tauri, custom ZIP parser

Manga reader that opens ZIP and CBZ archives. Runs in the browser, as a desktop/mobile app (Tauri), or as a self-hosted server for LAN access. No accounts required.

#+html: <p align="center"><img src=".github/readme/home-mobile.jpeg" alt="Mobile home" width="260">&nbsp;&nbsp;<img src=".github/readme/manga-mobile.jpeg" alt="Mobile manga detail" width="260">&nbsp;&nbsp;<img src=".github/readme/reader-mobile.jpeg" alt="Mobile reader" width="260"></p>

* Features

- Vertical scroll mode and page-turn mode
- RTL reading support
- Hold =z= to zoom to cursor in page-turn mode
- Chapter and page progress saved to localStorage
- Offline downloads via IndexedDB
- Rebindable keyboard shortcuts
- Native Tauri 2 desktop app with file dialog
- Self-hosted server mode (native binary, no runtime to install) for LAN access
- Custom ZIP/CBZ parser with ZIP64 support, no third-party ZIP library
- One parser implementation in Rust, compiled to wasm for the browser and natively for the server

* Architecture

#+begin_src
src/lib/
├── actions/         # Svelte actions (intersect, edge swipe)
├── browsers/        # Source browser UIs (library, native, offline, upload)
├── chapters/        # EndOfChapter UI
├── commands/        # Command registry and keybinding actions
├── context/         # ReaderServices factory (createReaderServices)
├── events/          # Typed event bus
├── keyboard/        # Configurable keybindings + help overlay
├── pipeline/        # Image decode pipeline + preloader
├── plugins/         # Plugin system (runner, registry, window title)
├── sources/         # Data source abstraction (upload, server, Tauri, offline)
├── ui/              # Shared UI components (sidebar, toast, buttons)
├── utils/           # Constants, types, platform detection
├── viewers/         # Reading modes (scroll, page-turn) + viewer registry
└── zip/             # Byte-range plumbing around the wasm parser
#+end_src

The archive parser is a Rust workspace, built once and used everywhere:

#+begin_src
crates/
├── klparse/         # ZIP64 parsing, chapter grouping, JS-compatible collation
├── klwasm/          # wasm-bindgen bindings — the browser's no-backend path
└── klserver/        # axum binary — LAN sharing and self-hosted deployments
#+end_src

The browser and the server run the same parsing code, so a fix in one is a fix
in both. The wasm build keeps the lazy read behaviour that makes the plain
website work with no backend at all: opening a 2GB CBZ reads only the archive's
tail, its central directory, and the page on screen.

* Usage

** Browser

Visit the deployed site and drop a ZIP or CBZ file.

** Self-hosted server

The easiest way to share your library with a phone on the same network: open the
[[Desktop App (Tauri)][desktop app]], go to Settings -> Share to LAN, and scan the QR code with your
phone's camera app (the mobile app must already be installed). No separate
install or script needed.

For a headless/always-on setup (NAS, homelab box, no GUI), download and run the
starter script instead:

*** Linux / macOS

#+begin_src sh
curl -fSL https://github.com/NasreddinHodja/konigslibrary/raw/main/static/download/konigslibrary.sh -o konigslibrary.sh
chmod +x konigslibrary.sh
./konigslibrary.sh
#+end_src

*** Windows

Download =konigslibrary.bat= from =static/download/= and run it.

The script installs Bun if needed, builds the app, and starts a server on =http://localhost:3000=. LAN addresses are printed so other devices can connect.

*** Manual (Bun and Rust required)

#+begin_src sh
bun install
bun run serve
#+end_src

=bun run serve= builds the frontend, builds the =konigslibrary-server= binary,
and runs it. Once built, the binary is standalone — no Bun, Node or Rust needed
to run it, just the =build/= directory beside it:

#+begin_src sh
KL_STATIC_DIR=./build MANGA_DIR=~/Manga NO_BROWSER=1 \
  crates/target/release/konigslibrary-server
#+end_src

See =konigslibrary.service= for a systemd user unit that does exactly this.

Set =MANGA_DIR= to your manga directory:

#+begin_src sh
MANGA_DIR=~/Manga bun run serve
#+end_src

Or configure it through Settings in the UI (saved to =konigslibrary.json=).

** Desktop App (Tauri)

#+begin_src sh
bun run tauri:local          # dev mode
bun tauri build              # release build
#+end_src

** Android

A signed APK is available on the [[https://github.com/NasreddinHodja/konigslibrary/releases/latest][latest GitHub release]].

* Library Structure

Chapter detection is based on directory structure, not naming conventions.

** Local server / Tauri (directories)

#+begin_src
MANGA_DIR/
├── One Piece/              # manga, subfolders are chapters
│   ├── ch01/               # chapter, any folder name works
│   │   ├── 001.jpg
│   │   └── 002.jpg
│   ├── ch02/
│   │   └── 001.jpg
│   └── extras/             # also a chapter (every subfolder counts)
│       └── cover.png
├── Berserk/                # manga, images only = single chapter
│   ├── page01.png
│   └── page02.png
└── Naruto.cbz              # manga, ZIP with chapters from internal folders
#+end_src

- Each top-level entry in =MANGA_DIR= is one manga (directory or ZIP/CBZ)
- If a manga directory has subdirectories, each subdirectory is a chapter
- If it has only images at the root, it's treated as a single chapter
- Hidden files/folders (starting with =.=) are ignored

** ZIP/CBZ files (uploaded or on server)

The parser finds the longest common directory prefix shared by all images, then groups by the next directory level:

#+begin_src
manga.cbz
└── manga/                  # common root (auto-detected, stripped)
    ├── chapter_01/         # chapter
    │   ├── 01.png
    │   └── 02.png
    └── chapter_02/
        └── 01.png
#+end_src

If the ZIP has no subdirectories, it's treated as a single chapter.

** Sorting

Chapters sort lexicographically. Zero-pad folder names to get correct numeric order:

| Wrong           | Right            |
|-----------------+------------------|
| =ch1=, =ch10=, =ch2= | =ch01=, =ch02=, =ch10= |

** Supported image formats

JPEG, PNG, GIF, WebP, AVIF, BMP.

* Development

*Prerequisites:* [[https://bun.sh/][Bun]], and [[https://rustup.rs/][Rust]] for the archive parser:

#+begin_src sh
rustup target add wasm32-unknown-unknown
cargo install -f wasm-bindgen-cli --version 0.2.99  # must match crates/klwasm/Cargo.toml
#+end_src

#+begin_src sh
bun install
bun dev
#+end_src

| =bun dev=                  | Start dev server                     |

| =bun run tauri:local=      | Tauri dev mode                       |
| =bun tauri build=          | Tauri release build                  |

* Keyboard Shortcuts

All shortcuts are rebindable from Settings. Defaults:

| Key              | Action                                |
|------------------+---------------------------------------|
| =j= / =↓=       | Next page                             |
| =k= / =↑=       | Previous page                         |
| =l= / =→=       | Next page (prev in RTL)               |
| =h= / =←=       | Previous page (next in RTL)           |
| =n= / =]=       | Next chapter                          |
| =p= / =[=       | Previous chapter                      |
| =z= (hold)      | Zoom to cursor (page-turn mode)       |
| =s=              | Toggle sidebar                        |
| =b=              | Back to library                       |
| =m=              | Toggle scroll / page-turn mode        |
| =r=              | Toggle LTR / RTL                      |
| =-= / ===       | Zoom out / in (scroll mode)           |
| =?=              | Show keyboard shortcuts help          |
| =Escape=         | Close sidebar or help dialog          |

Click left/right halves of the page-turn viewer to navigate.
